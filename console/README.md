# Консоль проверки YARA

Python 3.12+ и установленная YARA. Дополнительные Python-пакеты не нужны.
Оболочка использует именно указанный исполняемый файл YARA, в том числе сборку
из этого форка. Сборка движка не выполняется автоматически.

## Windows

Скачайте ветку с этой папкой, установите Python и распакуйте YARA для Windows.
Сохраните официальный файл правил отдельно. В командной строке из корня репозитория:

```bat
py console/scan.py "C:\Users" --rules "C:\YARA\YARA_rules.yar" --yara "C:\YARA\yara64.exe" --timeout 60 --report report.jsonl
```

Для проверки системного диска замените `C:\Users` на `C:\`.
При необходимости доступа к защищённым файлам запустите терминал от администратора.
Начните с небольшой папки. Правила ИнфоТеКС не включены: их нужно скачать отдельно.

## Linux / macOS

```sh
python3 console/scan.py /path/to/files --rules /path/to/rules.yar --yara yara --report report.jsonl
```

Сначала консоль собирает список файлов, затем перед каждым запуском показывает
текущий путь, счётчик завершённых файлов, процент и время. Во время одного файла
новых строк может не быть до его завершения или истечения таймаута.
Процент относится к количеству файлов, а не к объёму данных или времени.
`Ctrl+C` останавливает проверку и сохраняет итоговый статус.

Отчёт JSONL содержит отдельные события для файлов, ошибок, таймаутов и итогов.
Существующий отчёт не перезаписывается: выберите новое имя или переместите старый.
Коды завершения: 0 — проверка завершена без совпадений и ошибок, 1 — найдены
совпадения, 2 — ошибки/таймауты, 130 — отмена. Пустая папка даёт 0 проверенных файлов.
Ошибки и таймауты означают неполную проверку; отсутствие совпадений не гарантирует
отсутствия вредоносного ПО. Срабатывания требуют анализа специалистом.

Символические ссылки и вложенные Windows junctions пропускаются. Правила,
исполняемый файл и текущий отчёт исключены из списка. Архивы не распаковываются.
На каждый файл запускается отдельный процесс: это позволяет ограничить время
и остановить его, но повторно компилирует правила и замедляет большие проверки.
Это первый прототип; на Windows его необходимо проверить с вашей сборкой YARA.
Отчёт может содержать чувствительные пути и метаданные — не публикуйте его в GitHub.
